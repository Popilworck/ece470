ECE 470 Lab 4 使用说明

已按照 Lab4_Manual.pdf 完成 UR3e 肘部向上（elbow-up）逆运动学，实现世界坐标与基座坐标转换、六个关节角求解、Lab 3 正运动学回代检查和编码器角度转换。位置输入为米，yaw 输入为度，发送给 ROS 的关节角为弧度。

已更新原有 Git 克隆到 839462c。原仓库包含另一台电脑生成的 build/install/log 文件；本次采用独立目录 .lab4-build、.lab4-install、.lab4-log 编译，保留原文件。每个运行终端必须加载本次生成的安装目录。

1. 编译及离线验证

cd /home/xliu173/ece470/ece470lab/lab_files
source /opt/ros/jazzy/setup.bash
colcon --log-base .lab4-log build --base-paths src \
  --build-base .lab4-build --install-base .lab4-install --symlink-install
source .lab4-install/local_setup.bash
ros2 run ece470labs lab4_exec 0.1 0.1 0.15 90 --dry-run

--dry-run 只计算和打印结果，不创建 ROS 节点，也不发送运动指令。上述例子的正运动学回代位置为 (0.100, 0.100, 0.150) m，yaw 为 90°，编码器角度约为 [128.554, −98.241, 127.000, −118.759, −90.000, −51.446]°。

cd /home/xliu173/ece470
python3 -m pytest -q lab4/test_lab4.py

17 项数值测试涵盖 200 个由原有正运动学生成的位姿、不同象限、yaw 周期、运动学边界与非法输入。还可在 ROS 环境加载后运行 python3 -m pytest -q lab4/test_lab4_exec.py，验证命令解析、轨迹消息及关节反馈处理。

3. 报告与实测数据

英文报告 PDF 草稿 / 可编辑的 HTML 版本 已包含六个关节的推导、三张原创矢量图、六组建议测试点、数值验证和误差讨论框架。请依据你的理解审阅，并补全个人信息和实验结论。

尚未执行实体机器人运动或取得尺量数据。用尺和直角尺在手册定义的世界坐标系中测量吸盘位置，将结果以米填写到 measurements.csv 的 measured_x_m、measured_y_m、measured_z_m。可以按实验台的实际可用空间修改测试点；每行的三个测量值应同时填写。然后重新生成：

cd /home/xliu173/ece470
python3 lab4/generate_report.py

脚本将重算欧氏距离标量误差，更新 measurement_results.csv、numerical_validation.csv、HTML 和 PDF。PDF 导出使用已安装的 Google Chrome。填写姓名、搭档、TA、section、提交日期，并根据实测结果完成讨论和结论后，再提交 GradeScope。TA 演示仍需现场运行两组不同目标。

修改报告文字时请编辑 generate_report.py 中的模板，避免重新生成时覆盖修改。不要用正运动学计算位置代替尺量实测位置。
